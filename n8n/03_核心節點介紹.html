節點種類

九大節點類別

類別用途
Trigger啟動工作流程

AI & DataAI 轉換、彙總、試算表工具

三種基本角色

Trigger · Action · Core

TRIGGER啟動流程的起點
ACTION在 App 裡做一件事
CORE邏輯與資料操作

Trigger、邏輯、整合三類，涵蓋 80% workflow 會用到的節點。

核心節點 — 觸發

三種 Trigger

Trigger用途
Manual測試與 debug，課堂 demo 常用
Webhook接收外部 HTTP 請求、表單、整合
Cron定時執行：報表、同步、通知

核心節點 — 邏輯

邏輯控制節點

節點用途
IF條件判斷：訂單分類、資料篩選
Switch多條件分支：狀態處理、分流
Function寫 JavaScript：處理、計算、轉換

核心節點 — 整合

常用整合節點

節點用途
HTTP Request呼叫 API（URL / Method / Headers / Body）
Email自動報表、系統通知、任務提醒
Webhook API接收表單、CRM、App 整合資料
