什麼是 n8n

nodemation ＝ Node + Automation

開源工作流程自動化工具，類似 Zapier / Integromat
更彈性、可自我託管（self-hosted）
串接各種 App、API、資料庫與服務
視覺化、可拖曳的節點式設計
TRIGGER觸發事件啟動流程
→
PROCESS處理轉換與判斷資料
→
ACTION動作寫回系統／通知

核心特色

為什麼選 n8n

視覺化編輯拖曳式流程設計器
自訂程式可寫 JavaScript 邏輯
Webhook接收外部即時請求
API 整合呼叫任何 REST API
大量整合Slack、Sheets、MySQL、Notion…
開源自架可自我託管、彈性高

為什麼需要自動化

兩大痛點

重複作業耗時易錯

  • 手動複製貼上（Excel ↔ 系統）
  • 每天重複整理報表、寄信通知
  • 人工流程不一致，品質難控管

系統無法互通

  • CRM、表單、Sheets、Email 分散
  • 資料更新不即時
  • 跨系統人工同步，風險高

痛點 → 解決方案

三個真實案例

情境原本的痛點n8n 自動化
Excel 報表人工整理、寄信、更新 CRM，高錯誤率表格更新 → 自動生成報表 → 自動寄出
行銷通知每天整理匯出、寄信，耗時 30–60 分表單 → Sheets → Email → CRM → Slack 通知
跨系統同步各團隊系統不同，需人工同步Sheets ↔ CRM、API ↔ DB 自動整合

n8n 安裝

三種安裝方式

方式優點備註
Desktop最簡單，適合初學者適合個人使用
Docker可正式部署、易管理需對 Docker 有基本了解
雲端部署VPS / Railway / Render 等需具備雲端知識

Windows 本地端安裝

Docker 五步驟

  • 1

    安裝 Docker Desktop（需 WSL2）並啟動

  • 2

    建立資料夾 C:\n8n 存放資料

  • 3

    docker run 掛載 volume 啟動 n8n

  • 4

    瀏覽器開 http://localhost:5678

  • 5

    改用 -d 背景執行（建議）
